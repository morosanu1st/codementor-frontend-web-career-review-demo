# Frontend Web Career Review Demo

A small **vanilla HTML/CSS/JS** demo for Codementor 1:1 tutoring on **project management**, **front-end**, and **web design**.

Built by **Mihai Chindriș** to show how a live mentoring session can combine a structured website review with a practical career roadmap for junior web developers.

## What this demo shows

Open `index.html` in any browser (no build tools, no install).

The page models a clean portfolio / landing layout with:

- **Hero** — clear value proposition and primary CTAs
- **Skills** — grouped by intent (foundations, design, delivery, growth)
- **Projects** — short cards with problem → build → learn framing
- **Career path checklist** — interactive junior web-dev milestones (saved in `localStorage` for this demo)
- **Contact** — next-step CTA toward a booked session

Accessibility notes are baked in: skip link, landmarks (`header` / `main` / `nav` / `footer`), labeled checklist controls, focus styles, and a live region for checklist progress.

## How I’d help in a 1:1 session

### 1. Website review checklist

We’ll walk your current site (or this structure applied to yours) with a mentor lens:

| Area | What we look at |
|------|-----------------|
| **UX** | Hierarchy, CTAs, whitespace, scannability, mobile flow |
| **Semantics** | Heading order, landmarks, forms/labels, meaningful link text |
| **Performance** | Lean assets, avoid unused JS/CSS, image strategy, no unnecessary tooling |
| **Responsive** | Breakpoints, readable type, touch targets, layout collapse |

You’ll leave with prioritized fixes — not a vague “make it nicer” list.

### 2. Front-end fundamentals coaching

Depending on where you are, we deepen:

- HTML structure and accessible markup
- CSS layout (Flexbox / Grid), spacing systems, typography
- Progressive vanilla JS for real UI behavior
- Design consistency so the site feels intentional, not assembled

### 3. Practical web-dev career roadmap

We turn learning into a plan:

- What to ship next on your portfolio
- Skills order that matches junior hiring signals
- Light project management habits (scope → ship → feedback)
- How to talk about your work in applications and interviews

The on-page checklist is a starting map; in session we personalize it to your goals and timeline.
